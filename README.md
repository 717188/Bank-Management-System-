# 🏦 Bank Management System (C Language)

## 📌 Overview

This project is a **Bank Management System** developed using the C programming language. It allows users to create accounts, deposit and withdraw money, and manage basic banking operations efficiently.

## 🎯 Objectives

* Develop a simple banking system using C
* Apply programming concepts like functions, arrays, and file/database handling
* Simulate real-world banking operations

## ⚙️ Features

* Account Registration
* User Login System
* Deposit Money
* Withdraw Money
* Check Account Details
* View Account Balance
* Transaction Handling

## 🧩 System Design

The system is designed using basic components:

* **Entities:** Account, Account Holder, Transaction
* **Attributes:** Account Number, Balance, Name, Transaction ID
* **Relationships:** Account Holder owns Account, Account has Transactions

## 🛠️ Technologies Used

* C Programming Language
* MySQL (for database integration)
* Standard Libraries:

  * stdio.h
  * stdlib.h
  * string.h

## 🔐 Security Features

* User authentication with PIN
* Basic access control
* Data handling with secure queries (MySQL)

## 🚀 Additional Features

* Multi-factor authentication (concept)
* Notifications and alerts (concept)
* Future mobile banking support
